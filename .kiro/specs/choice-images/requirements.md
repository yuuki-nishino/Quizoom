# Requirements Document

## Project Description (Input)
クイズの選択肢に画像を添付できるようにする(GitHub Issue #36)。

### 背景
- 現状、設問には画像を1枚添付できる(R2保存、jpeg/png/webp、上限5MB、リサイズ処理なし)が、選択肢は文言のみで画像を持てない。
- 投影画面は設問画像の下に、選択肢を2列グリッドで文言のみ表示している。

### 目的
各選択肢に画像を添付でき、投影画面・正解発表画面・プレビューで表示できるようにする。

### 要点
- **選択肢への画像添付**: 各選択肢に画像を添付できる(任意)。画像とテキストを併用でき、テキストは任意(画像のみの選択肢も可)。画像もテキストもない選択肢は不可。文言のみの既存設問は従来どおり動作する(後方互換)。設問画像と選択肢画像は併用できる。
- **投影画面での表示**: 選択肢の数(2択/4択)だけ画像を表示する。設問文・設問画像・選択肢画像・カウントダウン・回答状況を同時に表示しても、画面からはみ出さず、スクロールなしで全て見える。
- **正解発表画面**: 正解の選択肢の画像が分かるように表示する。回答数・割合の内訳表示とも両立させる。
- **画像サイズ・縮尺の統一**: アップロード時にブラウザ側(canvas)で、固定アスペクト比への中央トリミングと長辺の縮小を自動で行ってから送信する。トリミング位置の調整UIは作らない。既存のサーバー側検証(形式・サイズ上限)は維持する。
- **設問単位のプレビュー**: 設問編集画面から、その設問だけの投影画面プレビューを新しいタブで開ける。未保存の編集内容(設問文・選択肢・正解・添付画像)も反映する。投影画面と同じコンポーネント・テーマ・縦横比で表示し、設問表示と正解発表の両方を確認できる。
- **スコープ外(要検討)**: 参加者画面(スマホ)への画像表示と、そのプレビュー。投影画面のデザインを見てから判断する。

### 実装時の検討事項(設計フェーズで決める)
- 固定アスペクト比と長辺の上限サイズの具体値
- 選択肢画像の保存方法(D1のマイグレーション、`OptionSnapshot`の拡張)と、メディア配信の認可の再利用
- プレビューへの未保存内容の受け渡し方式(タブ間通信)と、編集中の変更の反映方法
