- [x] 1.3 D1スキーマとマイグレーション定義

- [x] 2. コア: ドメイン純粋ロジック
- [x] 2.1 (P) ScoringModule: 正誤判定・集計・順位決定の実装
  - `judge`（正誤判定）、`aggregate`（正解数・合計回答時間の集計）、`rank`（順位付け）を Cloudflare 固有 API に依存しない純粋関数として実装する
  - 順位は「正解数降順 → 合計回答時間昇順 → 参加登録順 `joinedSeq` 昇順」の全順序で決定し、同率が発生しないことを保証する
  - 不正解・未回答の設問を合計回答時間に加算しない集計ロジックを実装する
  - 途中参加者を特別扱いせず、参加登録より前に締切済みの設問を未回答として扱う
  - 性質テストとして「正解数・合計時間が完全一致する入力でも順位が重複しない」ことを検証する
  - 観測可能な完了条件: 単体テストで同率入力・未回答混在入力・途中参加入力の3パターンが期待どおりの順位を返す
  - _Requirements: 8.1, 8.2, 8.3, 8.4, 8.5, 8.6, 8.7, 8.8, 8.9_
  - _Boundary: ScoringModule_

- [x] 2.2 (P) PhaseMachine: フェーズ遷移規則とアラーム意図の実装
  - `LivePhase` の全遷移（`lobby`→`ready`→`questionOpen`→`questionClosed`→`revealed`→`interimRanking`→`finalRanking`、および `paused`）を純粋関数 `next` として実装する
  - 不正な遷移（例: `lobby` からの `closeQuestion`）を `INVALID_PHASE` として拒否する
  - 最終設問の `revealed` からの `nextQuestion` は `NO_NEXT_QUESTION` を返し、`finalize` のみを受理する
  - `reopenQuestion` は `questionClosed` からのみ許可し、`revealed` に対しては `ALREADY_REVEALED` を返す
  - `pause` は `questionOpen` からのみ許可し、`resume` 時に停止時間分だけ締切時刻を後ろへずらす
  - 各遷移に対応する `AlarmIntent`（`set`／`clear`／`noop`）を戻り値に含め、「アラームのライフサイクル」表の規則を実装する
  - 観測可能な完了条件: 単体テストで、許可されない遷移が拒否されること、`pause`→`resume` で締切時刻がずれること、各遷移のアラーム意図が設計表と一致することを確認できる
  - _Requirements: 5.2, 5.4, 5.5, 5.7, 5.8, 5.9, 5.11, 5.12, 5.13, 12.1_
  - _Boundary: PhaseMachine_
