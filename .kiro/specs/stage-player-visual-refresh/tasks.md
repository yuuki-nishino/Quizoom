# Implementation Plan

- [x] 1. Foundation: デザインテンプレートカタログとテーマ型の拡張
- [x] 1.1 デザインテンプレートカタログの実装
  - `standard` / `elegant-wedding` / `fancy-party` の識別子・名称・対象シーン説明・既定配色(4色)を持つ静的カタログを実装する
  - 未知の識別子または`null`を渡した場合に`standard`へフォールバックする解決関数を実装する
  - 各テンプレートの既定配色が文字色/背景色間でコントラスト比4.5:1以上であることを検証するテストを書き、パスさせる
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.7, 6.3_

- [x] 1.2 ThemeSettings型へのtemplateId追加
  - 共有ドメイン型にテンプレート識別子フィールド(null許容)を追加する
  - 結果共有ページ専用の縮小型は変更しないことを確認する(型チェックが通る)
  - _Requirements: 3.5, 4.1_

- [x] 2. Foundation: サーバー側の永続化とバリデーション拡張
- [x] 2.1 theme テーブルへの template_id 列追加
  - D1マイグレーションでnullable な列を追加する
  - マイグレーション適用後、既存イベントのテーマ行が引き続き読み出せることを確認する
  - _Requirements: 3.5, 4.3_

- [x] 2.2 外観設定リクエストのバリデーション拡張
  - 外観設定保存APIのリクエストスキーマに、テンプレートカタログの識別子集合に基づく検証を追加する
  - カタログに存在しない識別子を含むリクエストが400エラーで拒否されることをテストで確認する
  - _Requirements: 3.5_
  - _Depends: 1.1, 2.1_

- [x] 2.3 カタログリポジトリのテンプレートID永続化対応
  - テーマ設定の読み書き・イベント複製処理をテンプレートIDを含めて拡張する
  - 新規イベント作成直後はテンプレート未選択(null)として保存されることを確認する
  - イベント複製時に選択中のテンプレートIDが複製先イベントへ引き継がれることをテストで確認する
  - 既存の匿名配色プリセット(サーバー側)を削除し、参照していたテストをテンプレートカタログ参照へ更新する
  - _Requirements: 3.5, 3.6, 4.1, 4.2, 4.3_
  - _Depends: 1.1, 1.2, 2.1, 2.2_

- [ ] 3. Core: 表示基盤(ThemeProvider・テンプレート別装飾CSS)
- [ ] 3.1 (P) ThemeProviderのテンプレート属性反映
  - `ThemeProvider`にテンプレート識別子を受け取るプロパティを追加し、DOM属性として出力する
  - テンプレート未指定時は`standard`相当の属性値にフォールバックすることをテストで確認する
  - 配色反映が既存どおり`:root`の`@theme`トークンへの直接設定のみで行われ、別名変数を介した二重参照を再度持ち込んでいないことをテストで確認する
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.6, 5.2, 6.3_
  - _Boundary: ThemeProvider_
  - _Depends: 1.2_

- [ ] 3.2 (P) テンプレート別装飾CSSの実装
  - 3種のテンプレートそれぞれについて、ThemeProviderが出力する属性値をセレクタとした装飾スタイル(常時表示のアンビエント装飾層、フェーズ遷移の視覚表現)を実装する
  - アニメーションは`transform`/`opacity`のみを用い、進行操作の同期反映を遅延させないことを確認する
  - `prefers-reduced-motion`が有効な環境では非本質的な装飾アニメーションを抑制することを確認する
  - 実装前にui-ux-pro-maxスキルの`ux`ドメイン(アニメーションの継続時間・「1画面あたり1〜2要素まで」等のガイドライン)を参照し、装飾アニメーションの設計に反映する
  - ブラウザで投影画面・回答画面それぞれの各フェーズを表示し、3テンプレートいずれでも文字が視認できることを目視確認する
  - _Requirements: 1.1, 1.2, 1.5, 1.6, 2.1, 2.2, 2.3, 2.7, 5.1, 5.2, 6.2_
  - _Boundary: styles.css_
  - _Depends: 3.1_

- [ ] 4. (P) Core: 一過性の祝福演出コンポーネント(Confetti)の実装
  - 正解発表・最終ランキング確定・自分の好結果表示で使う、状態を持たない一過性(ループしない)の演出コンポーネントを実装する
  - `prefers-reduced-motion`が有効な場合は演出を抑制した表示になることをテストで確認する
  - 実装前にui-ux-pro-maxスキルの`ux`ドメイン(継続アニメーションを避ける、`transform`/`opacity`のみを使う)と`icons`ドメイン(祝福演出に添えるアイコンを使う場合、絵文字ではなくSVGアイコンを選定する)を参照する
  - 配色は`ThemeProvider`が設定する`--color-brand-*`トークンを参照し、テンプレートごとに追加の分岐を持たないことを確認する
  - _Requirements: 1.3, 1.4, 2.5, 2.6, 5.2, 6.3_
  - _Boundary: Confetti_

- [ ] 5. Core: 主催者向けテンプレート選択UI(ThemeEditor)の刷新
  - 既存の匿名配色プリセットswatchを、名称・対象シーンが分かるテンプレートカード(カタログ由来)へ置き換える
  - テンプレート選択時に4色とテンプレートIDの両方がフォームstateへ反映されることを確認する
  - テンプレート選択後に基調色などを個別調整しても、選択中テンプレートIDが保持されたままであることをテストで確認する
  - 既存の低コントラスト警告表示が、テンプレート選択後も引き続き機能することを確認する
  - 既存の匿名配色プリセット定義ファイル(クライアント側)を削除し、参照していたテストをテンプレートカタログ参照へ更新する
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 4.5, 6.3_
  - _Boundary: ThemeEditor_
  - _Depends: 1.1, 2.2, 2.3_

  - 既存の情報(参加者数・残り時間カウントダウン等)が引き続き表示されることをテストで確認する

  - 正解発表時に演出が表示され、`prefers-reduced-motion`環境では抑制されることをテストで確認する

  - 実装前にui-ux-pro-maxスキルの`icons`ドメインを参照し、上位者を示すアイコン(トロフィー・王冠等、使用する場合)を絵文字ではなくSVGアイコンから選定する
