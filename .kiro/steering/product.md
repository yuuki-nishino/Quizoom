# Product Overview

Quizoom は、会場に集まった参加者が一斉に回答するリアルタイムクイズ大会を、Webブラウザだけで実施できる汎用クイズ大会ツールである。

特定の用途に限定せず、結婚式の披露宴・二次会、社内イベント、懇親会、勉強会、学校行事、展示会、オンライン配信など、人が集まる場全般での利用を想定する。

## Core Capabilities

- **事前準備**: 主催者(ホスト)がGoogleアカウントでログインし、イベント・設問(問題文/選択肢/正解/制限時間/画像)・外観(配色/ロゴ/背景)を事前に作成・編集する
- **3画面同期進行**: 主催者の「進行画面」からの操作(出題・締切・正解発表・ランキング表示)を、「問題投影画面」(会場スクリーン)と「回答画面」(参加者のスマートフォン)へ1秒以内に同期する
- **QRコード参加**: 参加者はQRコード読み取りだけでニックネーム登録のみで参加でき、アプリのインストールやアカウント登録は不要
- **同率なし採点**: 正解数を第一基準、回答所要時間を第二基準として順位を決定し、大人数でも同率順位が発生しない
- **結果共有**: 開催後、主催者が任意で結果を認証不要の閲覧専用ページとして共有できる

## Target Use Cases

- 大画面(プロジェクター等)と参加者のスマートフォンが両方使える会場でのライブクイズ大会
- 年に数回程度の低頻度開催(常時運用ではない)を前提とした、開催していない期間の運用コストがほぼゼロの構成

## Value Proposition

- 参加者側はアカウント登録・アプリインストール不要で、QRコードを読むだけで即座に参加できる
- 正解数だけでなく回答スピードも順位に反映するため、表彰時に同率で困らない
- Cloudflareのサーバーレス構成により、イベント開催時以外は固定費が発生しない
