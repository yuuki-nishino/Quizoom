# Product Overview

Quizoom は、会場に集まった参加者が一斉に回答するリアルタイムクイズ大会を、Webブラウザだけで実施できる汎用クイズ大会ツールである。

特定の用途に限定せず、結婚式の披露宴・二次会、社内イベント、懇親会、勉強会、学校行事、展示会、オンライン配信など、人が集まる場全般での利用を想定する。

## Core Capabilities

- **事前準備**: 主催者(ホスト)がGoogleアカウントでログインし、イベント・設問(問題文/選択肢/選択肢ごとの画像/正解/制限時間/問題添付画像)・外観(配色テンプレート/ロゴ/背景)を事前に作成・編集する。設問単位で投影・回答画面のプレビューを確認できる
- **共同運営**: 所有者は他のGoogleアカウントを共同運営者として招待URLで招待できる(メール送信は行わない)。進行操作・設問編集・外観変更・公開などは共同運営者にも許可し、イベント削除・共有設定変更・共同運営者の管理は所有者専用とする
- **3画面同期進行**: 主催者の「進行画面」(新しいタブで開く)からの操作(出題・締切・正解発表・ランキング表示)を、「問題投影画面」(会場スクリーン)と「回答画面」(参加者のスマートフォン)へ1秒以内に同期する。進行画面からの一覧・結果への導線は、進行を止めないようイベント終了後にのみ表示する
- **テスト問題モード**: 本番の前に、固定の練習問題1問で3画面の操作を確認できる。採点・ランキング・結果には一切含めない
- **最終結果発表の演出**: 最終ランキングは、1位から数えて5人単位のグループで、下位から主催者の操作で発表する(上位5位は1人ずつ)。自動タイマーに依存せず、司会者が会場の空気に合わせて進める
- **QRコード参加**: 参加者はQRコード読み取りだけでニックネーム登録のみで参加でき、アプリのインストールやアカウント登録は不要
- **同率なし採点**: 正解数を第一基準、回答所要時間を第二基準として順位を決定し、大人数でも同率順位が発生しない
- **結果共有**: 開催後、主催者が任意で結果を認証不要の閲覧専用ページとして共有できる

## Target Use Cases

- 大画面(プロジェクター等)と参加者のスマートフォンが両方使える会場でのライブクイズ大会
- 年に数回程度の低頻度開催(常時運用ではない)を前提とした、開催していない期間の運用コストがほぼゼロの構成

## Value Proposition

- 参加者側はアカウント登録・アプリインストール不要で、QRコードを読むだけで即座に参加できる
- 正解数だけでなく回答スピードも順位に反映するため、表彰時に同率で困らない
- Cloudflareのサーバーレス構成により、イベント開催時以外は固定費が発生しない

## Product Principles

- **発表の高揚感を損なわない**: 順位は途中経過では参加者へ見せない。最終発表の途中も、自分の順位は投影画面で発表された時点で手元へ表示する(伏せている間の値はサーバーから配信しない)
- **画面に出す値は要件で定める**: 内部IDではなく利用者に意味のある値(選択肢の文言など)を表示する。「どの値を・どの順で・0件のときどう見せるか」まで要件に書く
- **進行を止める操作を誤って押させない**: 進行中の画面には離脱につながる導線を出さない
